# 听听学堂

普通网址默认使用账号登录，已登录设备在会话有效期内直接进入学习。听读、导航和复习均可用，学习标记和继续学习位置会同步到账号。

登录页保留“暂时免登录学习”，或在网址后加 `?local=1`（放在 `#` 前），仅使用本机记录，不请求账户或云端记录 API。设置页“账号登录”可返回登录并迁入本机记录；原云端记录始终需要登录。Node 使用官方支持的 `request.json()`；公开 HTTPS 地址写入 Edge 签名票据，避免将云函数的内部 HTTP 转发地址误判为不安全访问。

手机、平板和电脑自适应的英语听读站，配合《每天五个词》纸质手册。首页与学习资料页提供四年级、五年级上下学期入口，音频均已保存为英美 MP3，播放不依赖在线语音生成服务。

## 四个学期

- **四上**：原 21 周、147 天、525 词、1050 句例句。原有链接、词条编号、音频和学习记录继续使用；资料卡片可打开“A4打印版”和“陪读版”两份原始 PDF。
- **四下**：2027-03-01 至 2027-07-31，共 153 天。3–6 月的 88 个学词日，每日 3 个教材词＋2 个适龄拓展词，周六复习、周日休息。440 为学习词次，去重后 325 个词条（149 个教材词、176 个拓展词），650 句例句。
- **7 月复习**：22 个工作日回顾全学期 325 个词，12 篇生活短文，每周 2–3 篇；支持英美整篇播放、逐句跟读、中文参考、理解题与答案。学生册和家长译文答案 PDF 可在资料入口下载。
- **五上**：2027-09-01 至 2028-01-15。76 个积累日，380 学习词次；120 个教材词全部在 12 月 15 日前首次安排完成，另有152个未在四年级词库出现的拓展词，共272个不同词条、544句例句。12月16日-1月15日复习全部272词，安排12篇原创短文。
- **五下**：2028-02-15 至 2028-07-31，含闰日2月29日。99个积累日，495学习词次；135个教材词全部在6月30日前首次安排完成，另有198个拓展词，共333个不同词条、666句例句。7月复习全部333词，安排11篇原创短文。

五年级每个积累日严格3教材词＋2适龄拓展词。单元词表覆盖常规词、词组和专名；五上另补附录3中的 everything。完整复习周每周2-3篇，五下最后一周只有7月31日，安排1篇收尾。复习含词汇回顾、3道理解题、2道填空、重读和表达；中文与答案收在陪读版。资料卡片统一按“A4打印版、陪读版”排列。

五年级资料依据人教社当前公开新版PEP五上《Different friends》等6个单元及五下《Following the rules》等6个单元，未声称已核实2027-2028新印次。每词记录教材单元与页码、剑桥双音标来源（同形词另核对词性），以及两句带中文和场景的原创例句。词组的分词音标会显式注明，连读以音频为准。可编辑来源和覆盖报告见 [source/grade5/README.md](source/grade5/README.md)。

四下沿用本次已核对的打印稿，教材对应当前公开新版人教 PEP 四下，2027 春季新印本尚未核实；短文按已确认频率原创编排。词条保留教材位置和发音参考信息，导入来源的 SHA-256 与数量检查见 `source/spring-content-checks.json`。

四个学期分别保存继续学习位置，所有词的标记可跨设备合并。旧 `#/day/32/0` 等链接仍打开四上，四下使用 `#/spring/…`；五年级入口为 `#/grade5-autumn/english`、`#/grade5-spring/english`。旧词库、音频和进度字段保持兼容；四学期完整记录为1455个词标记及4个独立位置。

## 留言与开发者回复

设置页的“留言”普通点击仅显示“该模块尚在开发”；连续快速点击 5 次进入留言板。界面不展示进入方法。入口手势只控制页面入口，不能授予开发者权限。

登录学习账号后可发送文字、PDF 或图片，查看该账号历史留言与回复，也可追加说明。每次最多 5000 字、3 个附件，单个 5 MB、合计 10 MB；支持 PDF、PNG、JPG、WebP、GIF。附件分片保存到现有 `LEARNING_KV`，仅相应账号和已验证开发者可读取，所有留言接口和附件均禁止缓存。

开发者在留言板展开“开发者回复”，输入开发者密码验证后回复。密码通过 Node.js 原生 PBKDF2-SHA256（600000 次、32 字节随机盐）校验，私有 KV 只保存加盐校验值。浏览器不保存密码；Edge 发出与本次输入绑定的 AES-GCM 加密票据，Node 验证后返回短期证明，Edge 签发独立的 1 小时 HttpOnly Cookie。旧管理码停用；更换密码会让旧开发者会话和证明失效。

维护命令：运行 `node scripts/setup-feedback-password.mjs`，通过隐藏标准输入生成 `.private/feedback-password-verifier.json`（不含明文密码）；再运行 `python scripts/apply-feedback-password.py --origin https://www.study4better.cloud-ip.cc` 将校验值写入现有私有 KV。配置请求由既有会话密钥签名，无需增加环境变量。不要把密码放在命令参数、脚本、日志或仓库中。

只使用开发者身份时，可先通过 `?local=1#/settings` 打开设置，再按同样方式进入；留言服务仍独立验证管理身份。

发送与回复在服务端写入成功后才显示已保存，重试复用原消息编号，避免重复；多人回复使用独立记录。KV 最终一致，跨设备或跨节点读取新内容可能需要约 1 分钟，留言板提供刷新。未发出的草稿与附件保留在当前页面，尚不支持关闭页面后恢复草稿。未绑定附件 24 小时后拒绝使用，存储暂不自动清理；长期使用应关注 KV 用量。

## 学习签到

首页“签到与历史”打开月历：今日签到、查看历史、为过去未签到日期补签。补签在日历和历史列表中明确标注“补签”；未来日期不能签到。日期按北京时间划分，账号模式由服务端确定签到／补签类别并写入现有 KV，重复点击和并发请求按日期合并显示。读写均需学习账号、来源和 CSRF 验证，签名开发者身份不能代替学习账号签到。本机模式仅保存当前设备的签到；账号模式跨设备读取可能延迟约1分钟。

上下学期资料卡片统一叫“每日英语词汇”，PDF 链接依次为“A4打印版”“陪读版”，下载文件名包含学期。四份原 PDF 内容不变；四下陪读版仍是原译文与答案册。旧静态文件地址保留。

## 听读速度

单词页、短文页和设置页均可用滑块选择 0.50～1.50 倍速，步进 0.05，提供 0.6、0.8、1.0 倍快捷按钮。播放中立即调速并保留当前位置与连续播放队列；所有英美单词、例句和短文共用所选速度，保持原音调。倍速保存在当前设备，刷新和下次打开继续使用，已有 0.8 和 1.0 倍设置继续保留。

## 登录与记录

使用家长指定的固定账号，输入姓名拼音和六位验证码。服务端校验，HTTPS 下以 HttpOnly、Secure、SameSite Cookie 保持登录 30 天；浏览器不保存验证码。设置中可以退出登录。

浏览器先向 Edge 获取有效期 60 秒、绑定本次用户名和密码的限流票据，再直接请求同域 Node.js 云函数使用原生 PBKDF2 校验；Node 返回短期签名证明，Edge 验证后签发现有会话 Cookie。频控先记入 KV，防止省略失败上报；成功登录重置计数。继续使用当前四个账号环境变量，无需新增域名或配置。

学习标记和上次位置保存在腾讯云 **EdgeOne Pages KV**，另一台设备登录同一账号即可恢复。KV 最终一致，跨节点更新可能需要约 60 秒；页面提供同步状态和“立即同步”。断网时记录先进入本机持久队列，联网、切回页面或下次登录时重试。原浏览器学习标记首次登录后自动迁入账号；换域名需先导出旧站记录，再在新站恢复。

英美口音、速度和跟读停顿仍是各设备自己的偏好。没有注册功能或额外数据库服务器。

## 部署与开发

完整步骤见 [部署指南.md](部署指南.md)。先绑定变量 **LEARNING_KV** 的 KV 命名空间，导入本机 `.private/edgeone.env` 的四个环境变量，再重新部署。私有文件不提交 Git，不上传网页目录。

Git 部署：根目录为本仓库，构建 `npm run build`，输出 `dist`，Node 22+。无 npm 第三方依赖。

直接上传：`python scripts/package_static.py` 生成 `learning-station-edgeone.zip`，包含前端、全部音频、`edge-functions`、`cloud-functions` 与缓存配置。旧版纯静态包不能提供登录与同步。

`npm run dev` 启动 `http://127.0.0.1:8767/`，通过真实 HTTP 调用本地 Node 校验端点，用本机文件模拟 KV，不连接生产数据。真实 EdgeOne 调试：`edgeone login` 选择 China，`edgeone pages link` 关联项目，`edgeone pages dev` 调试。

`npm test` 覆盖错误登录、会话过期/篡改、CSRF、缓存禁用、跨设备合并、取消标记、KV 分页/延迟、存储失败、限流和离线补传；另校验四下 3＋2 日程、全部音频映射、独立学习位置、留言权限、附件上传下载、并行回复、失败重试及实际函数打包。测试使用虚构账号。

修改账号可运行 `npm run setup-account`，经隐藏标准输入提供账号 JSON，再把新配置导入 EdgeOne。不要将账号 JSON 放在 shell 参数或 Git 中。设置脚本只保存加盐校验值和随机会话密钥，不保存明文验证码。

## 文件与维护

- `dist/app.js`、`styles.css`、`progress-sync.js`、`courses.js`、`feedback.js`：前端源码。
- `dist/spring-data.json`、`spring-audio-manifest.json`、`materials/grade4-spring/`：四下词库、音频索引和打印材料。
- `dist/grade5-*-data.json`、`grade5-*-audio-manifest.json`、`materials/grade5-*/`：五年级上下学期资料、完整英美听读音频和PDF。
- `dist/course-schema.js`：前后端共享的学期词条与进度边界，构建时打入Edge函数。
- `server/learning-api.js`：认证、会话与 KV API，使用 Web Crypto 等边缘运行时 API。
- `server/feedback-api.js`：私有留言、附件与开发者身份验证，构建时一并打入 Edge 函数。
- `edge-functions/`：EdgeOne 文件路由入口。
- `server/node-password-verifier.js`、`cloud-functions/`：原生 Node 密码校验及平台云函数入口。
- `.private/`：本机账户配置与开发 KV，Git 忽略。
- `scripts/build.mjs`：准备部署产物，不读取或嵌入私有配置。
- `scripts/parse_source.py`、`generate_audio.py`、`finish_audio.py`：更新资料和音频，不是运行网站的依赖。
- `scripts/import_spring.py`、`generate_spring_audio.py`：从已核对四下稿导入日程并生成音频，复用内容完全相同的旧音频；临时批次不提交 Git。
- `scripts/build_grade5.py`、`build_grade5_pdfs.py`、`generate_grade5_audio.py`：从核对后的来源重建五年级日历、打印稿和音频。音频按内容哈希校验，更新文本后重新生成受影响片段。
- `source/`：内容和音频检查报告；原资料快照被 Git 忽略。
- `.openai/hosting.json`：历史 Sites 项目身份，当前 EdgeOne 不使用。

每个浏览器页面写入独立的不可变检查点，按词条逻辑版本合并；取消标记保留显式空值，避免旧记录复活。同词同时编辑时较高逻辑版本生效，同版本以写入端标识确定顺序。读取只取每个写入端的最新记录；历史检查点暂不自动删除，长期使用需关注 KV 用量。

接口验证会话、来源和格式，并禁用缓存。KV 最终一致使应用限流属于辅助保护，生产还应配置平台登录接口速率限制。学习记录 API 需要登录，普通资料和音频仍是公开静态资源。
